Лабораторная 4. Отсечение отрезков и многоугольников

Синий – отсекающее окно, красный пунктир – исходные данные, зелёный – видимая (отсечённая) часть.

Пояснения

Алгоритм Сазерленда–Коэна. Каждому концу отрезка присваивается 4-битный код области: бит 1 – левее xmin, 2 – правее xmax, 4 – ниже ymin, 8 – выше ymax. Если оба кода равны 0 – отрезок полностью видим; если (код₁ AND код₂) ≠ 0 – оба конца по одну внешнюю сторону, отрезок полностью невидим. Иначе внешний конец переносится в точку пересечения с границей окна по явному уравнению прямой y = y₁ + k(x − x₁), k = (y₂ − y₁)/(x₂ − x₁) (для x = xmin / xmax) или x = x₁ + (y − y₁)/k (для y = ymin / ymax); затем коды пересчитываются и проверка повторяется.

Алгоритм Лианга–Барски. Параметрическое задание отрезка P(t) = P₁ + t(P₂ − P₁), t ∈ [0, 1]. Точка внутри окна, если pi·t ≤ qi для p = (−Δx, Δx, −Δy, Δy), q = (x₁ − xmin, xmax − x₁, y₁ − ymin, ymax − y₁). pi < 0 – отрезок входит в полуплоскость: t₀ = max(t₀, qi/pi); pi > 0 – выходит: t₁ = min(t₁, qi/pi); pi = 0 и qi < 0 – отрезок параллелен границе и лежит снаружи. Видимая часть – [t₀, t₁], если t₀ ≤ t₁.

Алгоритм средней точки. Коды Сазерленда–Коэна используются только для тривиального принятия/отбрасывания. Отрезок, который нельзя тривиально принять или отбросить, делится пополам, и обе половины обрабатываются рекурсивно, пока части не станут тривиально видимыми/невидимыми или короче 10⁻⁶. Видимая часть – от первой до последней видимой части. Нужны только сложения и деление на 2 (удобно для аппаратной реализации).

Алгоритм Кируса–Бека (отсечение отрезков выпуклым многоугольником). Обобщение алгоритма Лианга–Барски. Для каждого ребра многоугольника с внутренней нормалью n и точкой A на нём точка P(t) лежит во внутренней полуплоскости, если n·(P(t) − A) ≥ 0, т.е. n·(P₁ − A) + t·n·D ≥ 0, где D = P₂ − P₁. Если n·D > 0 – получаем нижнюю границу для t (вход), если n·D < 0 – верхнюю (выход). Многоугольник должен быть выпуклым; порядок обхода вершин определяется автоматически.

Алгоритм Сазерленда–Ходжмана (отсечение выпуклого многоугольника прямоугольником). Многоугольник последовательно отсекается четырьмя границами окна. Для каждого ребра (S → P) текущего многоугольника: оба внутри – выводим P; S внутри, P снаружи – выводим точку пересечения; оба снаружи – ничего; S снаружи, P внутри – выводим точку пересечения и P. Результат для одной границы – вход для следующей.
