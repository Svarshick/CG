Лабораторная 3. Базовые растровые алгоритмы

Колесо мыши – масштаб, перетаскивание – сдвиг.

Пошаговые вычисления

Время работы

Каждый алгоритм многократно запускается на текущих данных ~150 мс (без отрисовки); показано среднее время одного запуска.

Пояснения

Привязка целочисленных координат к сетке. Пиксель – это клетка сетки. Пиксель с целыми координатами (x, y) – это клетка, центр которой находится в точке (x, y); её границы – линии x ± 0.5 и y ± 0.5 (тонкие серые линии сетки). Поэтому оси проходят через центры строки 0 и столбца 0, а идеальный отрезок из (x₀, y₀) в (x₁, y₁) проходит точно через центры его концевых пикселей. Алгоритм растеризации на каждом шаге вдоль главной оси решает, какая клетка ближе всего к идеальной линии.

Пошаговый алгоритм. Использует явное уравнение прямой y = kx + b, k = Δy/Δx, b = y₀ − kx₀. x пробегает все целые значения от x₀ до x₁, y = round(kx + b). Если |Δy| > |Δx|, роли x и y меняются (x = round(k'y + b')), иначе в линии были бы разрывы. На каждом шаге нужно умножение и округление вещественного числа.

ЦДА (цифровой дифференциальный анализатор). L = max(|Δx|, |Δy|) шагов. Приращения dx = Δx/L, dy = Δy/L (одно из них равно ±1). x, y начинаются в (x₀, y₀), на каждом шаге x += dx, y += dy; рисуется пиксель (round(x), round(y)). Только сложения, но в вещественных числах.

Алгоритм Брезенхема (отрезок). Только целочисленная арифметика. При dx = |Δx|, dy = |Δy| ошибка e = dx − dy показывает (в удвоенном виде), насколько идеальная прямая отклонилась от текущего пикселя. На каждом шаге: e₂ = 2e; если e₂ > −dy, то e −= dy, x += sₓ; если e₂ < dx, то e += dx, y += s_y. Работает во всех октантах.

Алгоритм Брезенхема (окружность). Вычисляется только один октант (от (0, R), пока x ≤ y), каждая точка отражается 8 раз: (±x, ±y), (±y, ±x). Управляющая переменная d = 3 − 2R. Если d < 0, следующий пиксель (x+1, y) и d += 4x + 6; иначе следующий пиксель (x+1, y−1) и d += 4(x − y) + 10.

Сглаженная линия Ву (доп. задание). Для каждого x вдоль главной оси точное значение y лежит между двумя пикселями y и y+1. Рисуются оба пикселя с интенсивностью (1 − f) и f, где f – дробная часть y. Пиксели ближе к идеальной прямой темнее, поэтому «лесенка» сглаживается.
