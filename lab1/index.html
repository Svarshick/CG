Лабораторная 1. Цветовые модели: CMYK – RGB – HLS

Задайте цвет в любой модели: введите точные значения, двигайте ползунки или выберите цвет из палитры.
Две другие модели пересчитываются автоматически.

Используемые формулы

RGB – аддитивная модель (экраны). R, G, B ∈ [0, 255] – интенсивность красного, зелёного и синего света. Далее r = R/255, g = G/255, b = B/255.

CMYK – субтрактивная модель (печать). C, M, Y – количество голубой, пурпурной и жёлтой краски; K – чёрная краска. Все значения в [0, 100] %.
RGB → CMYK: K = 1 − max(r, g, b); C = (1 − r − K) / (1 − K); M = (1 − g − K) / (1 − K); Y = (1 − b − K) / (1 − K) (если K = 1, то C = M = Y = 0).
CMYK → RGB: R = 255·(1 − C)(1 − K), G = 255·(1 − M)(1 − K), B = 255·(1 − Y)(1 − K).

HLS – H (тон) – угол на цветовом круге: 0° красный, 120° зелёный, 240° синий; L (светлота) – 0 чёрный, 50% чистый цвет, 100 белый; S (насыщенность) – 0 серый, 100 чистый цвет.
RGB → HLS: max, min из (r, g, b), d = max − min; L = (max + min)/2; S = 0, если d = 0, иначе d/(max + min) при L ≤ 0.5, иначе d/(2 − max − min); H = 60·((g − b)/d mod 6), если max = r; 60·((b − r)/d + 2), если max = g; 60·((r − g)/d + 4), если max = b.
HLS → RGB: C = (1 − |2L − 1|)·S, X = C·(1 − |(H/60) mod 2 − 1|), m = L − C/2; (r', g', b') зависит от 60-градусного сектора H: (C,X,0), (X,C,0), (0,C,X), (0,X,C), (X,0,C), (C,0,X); затем R = 255(r' + m) и т.д.
